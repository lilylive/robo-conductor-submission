# ROBO CONDUCTOR：日本語の指示を順番に演奏する対話版

文字で入力した日本語の指示を、OpenAI APIで演奏計画に変換し、ロボットアームに演奏させます。例えば、最初に「赤、青、緑、赤の順番で叩いて」、演奏後に「きらきら星を弾いて」と入力できます。

AIは各指示を、赤・青・緑の順序、登録曲「きらきら星」、未対応のいずれかに分類します。きらきら星の譜面はあらかじめ用意したもので、AIは曲名の解釈と選択を担当します。関節の動きはPyBulletの逆運動学と位置制御で計算します。未登録の曲や不正な計画は演奏しません。AIの解釈結果は画面に表示しますが、意味の誤解が起きないことを保証するものではありません。

3色の指示は、8音パッドの実際の色に対応しています：赤＝ド（C4）、青＝ラ（A4）、緑＝ファ（F4）。色ごとの音程は以前の3色専用版とは異なります。実際の接触が検出されると、そのパッドの色を変え、対応する音を後から合成して映像に重ねます。

## Google Colab

`notebooks/ROBO_CONDUCTOR_対話版_Colab.ipynb` をColabにアップロードし、上から順番に実行します。OpenAI APIキーをColabのSecretsに `OPENAI_API_KEY` として登録し、ノートブックへのアクセスを許可してください。キーをセルに直接書かないでください。指示は毎回OpenAIのAPIに送信され、料金が発生する場合があります。最初の指示の映像を表示してから、次の指示を入力できます。

各指示につき1本ずつ動画・WAV・記録を作成します。現在は**各指示でシミュレーションを新しく開始するため、ロボットの姿勢は前の動画から連続しません**。完成した映像は動画編集ソフトでつなげます。

## Macから実行

README.mdに従ってPython環境を用意し、OpenAI APIキーを環境変数 `OPENAI_API_KEY` に設定した上で、次のコマンドを実行します。キーを公開リポジトリやチャットへ書き込まないでください。

```bash
python dialogue.py
```

指示を入力すると、AIの解釈を表示してから動画・音声・ログを生成します。生成が終わると次の指示を入力できます。Macのコマンド実行では生成動画を自動再生しないため、表示されたファイルを開いて確認してください。終了するには `/終了` と入力します。動画は `output/dialogue/` 以下に、既存ファイルを上書きしない番号付きの名前で保存します。

## 検証と制約

実際のOpenAI APIを呼び出さない模擬応答で、色指定の4打と、続くきらきら星の42打を別々のPyBulletシミュレーションで検証しました。それぞれ4/4、42/42の対象パッド接触を確認し、誤ったパッドへの接触は0件でした。APIへの送信は模擬しているため、この結果は実際のAIが指示を正しく理解した証拠ではありません。

新規のOpenAI API呼び出し、Google Colab実環境、実機のロボット、Final Cut Proへの読み込み、人による音の確認は未検証です。パッドの発光は表示色の変化、音は合成音です。接触力は未較正のシミュレーション値です。
